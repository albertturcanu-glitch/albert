# Quiz And Scoring Model

## Assessment Goal

The assessment does not diagnose addiction or predict success. It creates a relapse map that helps the user restart with clarity.

## Dimensions

### False Benefit

Measures what smoking seemed to provide:
- relief;
- reward;
- pause;
- control;
- belonging;
- identity.

### Fear Hook

Measures the story that made quitting feel costly:
- deprivation;
- stress incapacity;
- ruined-day thinking;
- special-occasion permission;
- perfect-start waiting.

### Friction Gap

Measures how easy it was to repeat:
- cigarettes accessible;
- routine unchanged;
- social trigger unplanned;
- no replacement pause;
- no support option.

### Return Energy

Measures how ready the user feels to restart now:
- clear;
- tired but willing;
- ashamed;
- skeptical;
- urgent.

## Scoring

Each item contributes to one or more dimensions. The report ranks dimensions by accumulated score.

Interpretation:
- high false benefit: focus on reframing the perceived value of smoking;
- high fear hook: focus on the fear of loss, deprivation, or inability to cope;
- high friction gap: focus on environment and next-moment planning;
- low return energy: focus on tiny restart actions and support, not big commitments.

## Report Tone

The report should sound like:
- "Here is the loop that pulled you back."
- "Here is the smallest move that breaks it."
- "This does not need to become your identity."

The report should not sound like:
- "You failed because..."
- "Just use willpower."
- "Start over from zero."
