# Quiz, Feedback & Final Report Upgrade

## Probleme actuale ale quiz-ului
- Prea scurt pentru profil comportamental complet.
- Fără explicații per răspuns.
- Fără corecție educațională pentru răspuns greșit/suboptim.
- Profil limitat (4 dimensiuni) și personalizare modestă a raportului.

## Structură nouă propusă
- Moduri:
  - Quick (3–5 min)
  - Standard (7–10 min)
  - Deep (12–15 min)
- Blocuri:
  - context și triggeri;
  - răspuns la craving;
  - reglare emoțională;
  - pattern de recădere;
  - suport și autoeficacitate.

## Tipuri de întrebări
- Single choice (scenarii).
- Multi-select (triggeri multipli).
- Likert (0–10).
- Mini-vignete (ce ai face în situația X).

## Feedback după fiecare răspuns
- Confirmare neutră.
- Explicație educațională scurtă.
- Dacă răspunsul e vulnerabil: micro-recomandare imediată.

## Explicații pentru răspunsuri greșite
- Ton: non-judicativ.
- Format: “de ce apare acest răspuns” + “ce variantă te protejează mai bine”.

## Scoruri pe dimensiuni (țintă)
- dependență fizică;
- triggeri contextuali;
- reglare emoțională;
- pregătire pentru schimbare;
- risc de recădere;
- strategii de coping;
- suport social;
- autoeficacitate.

## Model de raport final
- Rezumat profil.
- Puncte forte observate.
- Vulnerabilități active.
- Top 3 acțiuni pentru 24–72h.
- Plan compact pentru 7 zile.
- Decizie finală:
  - continuă;
  - ajustează;
  - cere suport;
  - repetă protocolul.

## Focus temporal recomandat
- 24–72h: micro-acțiuni de stabilizare.
- 7 zile: consolidare trigger map + coping + review.

## Riscuri speciale
- Supracomplexitate quiz -> abandon.
- Scoring opac -> neîncredere.
- Ton evaluativ -> rușinare.

## Gap față de prototip
- MVP-ul actual este bun ca “starter”, dar insuficient pentru raport personalizat de nivel strategic.
