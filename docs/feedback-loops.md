# Feedback Loops And System Model

## The Relapse Loop

Trigger -> old story -> permission thought -> cigarette -> shame or relief -> vague conclusion -> repeated vulnerability

The app interrupts the loop at three points:

- Story: what did smoking promise?
- Permission: what sentence made it acceptable?
- Recovery: what tiny action prevents the next loop from becoming automatic?

## The Freedom Loop

Trigger -> pause -> story named -> no-sacrifice reframe -> micro-action -> return signal -> confidence

The product should make the user feel the restart is already happening during the session.

## Key Variables

- Trigger intensity.
- Access to cigarettes/vape.
- Emotional state.
- Social context.
- Strength of false benefit.
- Presence of restart action.
- Shame level after the episode.

## Product Feedback

The app should reflect:

- "Your riskiest loop is..."
- "The false benefit that keeps returning is..."
- "The next restart action is..."
- "What to rehearse before the next high-risk moment..."

## What Not To Optimize

- Perfect streaks as the main measure.
- Health scare intensity.
- Daily guilt check-ins.
- Complex analytics before the first useful report.
