# Smoke-Free Return

Un app static pentru oameni care s-au lasat de fumat, au recidivat, si vor sa revina fara rusine.

## Cum il deschizi

Deschide `index.html` in browser.

## Ce contine MVP-ul

- un prim ecran cu promisiunea produsului;
- o harta a buclei de recadere;
- un sistem de daily streak cu niveluri, badge-uri si restart fara rusine;
- un tab `Become a student` cu 10 lectii Allen Carr-inspired;
- un self-check scurt;
- un raport cu bucla dominanta, micro-actiune si fallback de copiere;
- salvare locala separata pentru streak si planul de revenire.

## Verificare rapida

- seteaza data deciziei sau apasa `Incep azi`;
- deschide `Become a student` si verifica cele 10 lectii;
- completeaza self-check-ul;
- verifica raportul si butonul `Copiaza planul scurt`;
- copiaza intrebarile din sectiunea `Feedback`;
- pe mobil, confirma ca hero-ul, badge-urile si cardurile nu se suprapun.

## Launch prep

Primul pas recomandat este un share test local, nu un deploy public. Checklist-ul este in `docs/launch-prep.md`.

## Surse si limite

App-ul nu ofera sfat medical si nu inlocuieste sprijinul profesionist. Foloseste idei evidence-backed despre triggeri, sevraj, suport si medicatie, plus o directie Allen Carr-inspired: reducerea fricii, observarea iluziei beneficiului si revenirea la libertate fara rusine. Nu este afiliat si nu reproduce metoda oficiala.

Sursele operationale sunt in `docs/`.
